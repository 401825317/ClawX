# 电商主图 v1

交付一张可直接用于商品展示的图片。当前轮必须完成生成并交付结果，不能只写提示词、计划或待执行说明。

## 触发与预设契约

- 用户明确提到“电商主图”、“商品主图”、“白底主图”、“商品场景图”、“商品卖点图”、“ecommerce main image”或“product hero image”时，使用本 Skill。
- 图片模式中选择 `ecommerce-main-image` 预设时，按本 Skill 执行；预设只表达创作意图，绝不覆盖用户已经选择或运行时下发的模型、尺寸、质量。
- 用户只说“做一张商品图”但未指定类型时，先根据可确认的渠道、文案和附件判断；无法安全判断时，默认白底主图，不编造营销卖点。

## 类型

- 白底主图：商品主体完整、边缘干净、背景纯净；不添加未经要求的道具、徽章、价格或营销文字。
- 场景图：场景必须服务于商品用途和目标人群，商品仍是第一视觉主体；不得用氛围、遮挡或裁切改变商品事实。
- 卖点图：只表达用户提供或参考图中能够确认的卖点；文字简短、清晰、可读，不虚构规格、认证、价格、功效或活动信息。

## 参考图约束

- 有参考图时，商品结构、比例、包装形态、Logo、商标、原有文字、颜色、材质、接口、配件数量和包装信息均为不可擅自重绘的商品事实。
- 无法辨认的文字不得猜测、补全或重写；保留原图可辨认内容，必要时明确说明限制。
- 只允许改变用户明确要求的背景、构图、光线和已确认卖点呈现。任何与参考图冲突的生成结果必须视为失败，不得作为交付物。
- 用户明确要求改包装、Logo、文字、规格或产品结构时，先将其作为“新设计”而非“保持参考图”的任务；没有明确确认，不得自行作此转换。

## 运行时能力与执行

- 图片模型、尺寸和质量只消费当前 UClaw 运行时或图片工具返回的能力与默认值。本 Skill 不指定模型 ID、固定像素、固定比例或质量等级。
- 如果本轮未提供可用的运行时图片能力、模型目录或工具默认值，安全失败并说明“当前没有可用的图片生成能力”；不得猜测或伪造请求参数。
- 优先使用用户附件。快速模式不联网搜索额外素材。
- 先生成一次；只有结果存在明确问题时做一次定向修复，不重画已经正确的商品事实。
- 最终返回生成结果和工具提供的交付路径或媒体引用，不以计划、提示词草稿或待执行说明结束。
